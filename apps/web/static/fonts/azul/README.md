# Azul fonts

Source: [Marcellus](https://github.com/google/fonts/tree/main/ofl/marcellus) and
[Karla](https://github.com/google/fonts/tree/main/ofl/karla) in Google Fonts,
downloaded 2026-09-13. WOFF2 files were converted losslessly from upstream
`Marcellus-Regular.ttf` and `Karla[wght].ttf` using fontTools. No glyph subsetting;
English/Spanish accented letters and ¿¡ verified in both character maps.
Upstream OFL licences are included. Usage is scoped to Azul.
