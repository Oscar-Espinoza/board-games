# Current table font: Roboto Condensed

Roboto Condensed by the Roboto Project Authors, SIL OFL 1.1.
[License](RobotoCondensed-OFL.txt); [upstream](https://github.com/google/fonts/tree/main/ofl/robotocondensed).
Downloaded 2026-09-13 from Google Fonts v31. This is a visual approximation of the
supplied reference, not a claim to identify its original font. The table and its
dialogs use locally bundled variable WOFF2, weights 400–700, with `font-display: swap`.
There are no remote font requests at runtime.

- `roboto-condensed-latin.woff2`: https://fonts.gstatic.com/s/robotocondensed/v31/ieVl2ZhZI2eCN5jzbjEETS9weq8-19K7DQ.woff2
- `roboto-condensed-latin-ext.woff2`: https://fonts.gstatic.com/s/robotocondensed/v31/ieVl2ZhZI2eCN5jzbjEETS9weq8-19y7DRs5.woff2

Source CSS: `https://fonts.googleapis.com/css2?family=Roboto+Condensed:wght@400..700&display=swap`
(modern Chrome user agent). Latin and Latin extended cover English/Spanish.

The previous Archivo files are preserved below as design history; current CSS
no longer requests them.
