## Cross-game patterns noticed

- Every game has its own `pixel/sound.ts` (azul, carcassonne, catan, domino, little-secret, sushi-go-party, uno). `games/uno/src/pixel/sound.ts:30-38` and `games/catan/src/pixel/sound.ts:7-14` define the same `note(from, delay, duration, volume, type, to)` over `audio.tone(... attack: 0.002)` helper and a `thud`/`crunch` noise helper. Candidate for a shared `chiptuneKit(audio)` in `@board-games/shared/ui/pixel` (which already has `playChiptune`).
- `effects.ts` (azul, carcassonne, catan, codenames, little-secret, sushi-go-party) and `uno/motion.ts` all wrap `createAudio()` plus a "gesture unlock / enabled / cancel on stale revision / close" shell (`softAudio`, `cardAudio`). Catan's `generation` + 650 ms staleness (`effects.ts:520-528`) is an ad-hoc version of what `RevisionGate`/`eventGate` was meant to cover.
- Preference storage: `catan:*` uses `'true'/'false'`, `uno:*`, `carcassonne:*`, `domino:*` use `'on'/'off'`; motion is tri-state in uno and domino, boolean in catan, `&& !prefersReducedMotion` in carcassonne. A shared `preferences(game)` helper would remove four hand-written variants.
- Lazy 8-bit loading: UNO awaits `pixel.css` and `pixel/sound` together (`U/Board.svelte:63-72`), Catan only awaits CSS (`C/Board.svelte:80-83`) and statically bundles sound via `effects.ts`. Check other games for a third policy.
- `settingsContent` skin radio group (`name="uno-skin"`, `gameSkin`/`setGameSkin`) is copy-pasted per Board (`U/Board.svelte:313-328`, `C/Board.svelte:~935-960`).
- Host/board contract: `apps/web/src/routes/room/[id]/+page.svelte:186-206` passes a fixed bag of props; each Board picks a subset and the host special-cases games (`room.gameId === 'catan'`, `'carcassonne' || cornerControls`). Contract is not typed anywhere in `packages/shared`.
- Practice routes (`apps/web/src/routes/practice/{azul,carcassonne,catan,codenames,domino,little-secret,sushi-go-party}/+page.svelte`) each repeat lazy-Board-load + loading/error/retry; Catan's holds `view` as manual `$state`.
- Error messages thrown by rules are English sentences in UNO and Catan (and likely others), surfaced raw via `session.error`; there is no message-key convention.
- `GameDefinition` style differs: `uno ... satisfies GameDefinition<State>` vs `catan: GameDefinition<State>`.
- Python art pipeline per game (`games/catan/art/pixel-art.py`, `games/azul/scripts/pixel-art.py`) — two copies of the same box-downsample/octree script (`docs/catan-pixel.md:56`, `docs/azul-pixel.md:72`).
