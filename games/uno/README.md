# UNO

The former Rust `color-match` version-2 rules are ported to TypeScript in
`src/index.ts`. The shared room server owns this state; `view()` explicitly
projects public table information and only the requesting seat's hand/actions.
`Board.svelte` renders CSS cards using the original felt-table palette and loads
only when UNO is selected. English/Spanish labels are generated by Paraglide from `packages/shared/messages/`.

## Preserved rules

- 2–8 seats, seven cards each, 108-card deck; the first discard is a number.
- Match color or symbol. Drawing is optional and ends the turn.
- Skip skips the next seat. Reverse changes direction; with two seats it skips.
- +2 may answer +2; +4 may answer either +2 or +4. Taking the accumulated
  penalty ends the turn. No +4 challenges.
- Wilds require a separate color choice before the next turn or final-card win.
- Declare UNO before playing from a two-card hand. Without a declaration,
  opponents can catch until the next accepted play/draw, drawing two cards for
  the offender. Wild catch windows open after color selection. Rejected actions
  preserve windows and only one catch succeeds.
- Emptying a hand wins and clears penalties. No between-round scoring.
- Recycle earlier discards when the stock empties, preserving the top card.
  If cards run out, draw what remains. A full rotation of consecutive empty
  draws ends the round in a draw.

Server-supplied randomness replaces the native ChaCha replay machinery; old
seeded replay files are not a compatibility format. Tests inject deterministic
randomness. Normal rooms use human players. **Play solo** creates a private, server-authoritative
practice round with three computer opponents. Bots receive only their own
projected hand and legal choices, declare UNO, and pause while you disconnect.
Reconnect and rematch use the same room infrastructure as multiplayer.

Run `bun test games/uno/src/index.test.ts` from the repository root.

## Table presentation

The table fills the viewport, with each viewer at the south seat. Two players sit
north/south; three use south/west/east; four use all cardinal points. Larger
parties use fixed perimeter seats. The hand scrolls horizontally on small screens.

Accepted consecutive snapshots drive measured card flights: your played face
travels from its actual hand position to the discard, and stock backs travel to
your hand before revealing their face. Opponent draws use backs only. Initial
snapshots, reconnect, rematch, revision gaps, resize and hidden tabs cancel stale
presentation. Effects never delay or mutate authoritative state.

The UNO button arms a declaration when holding two cards; the declaration is
sent atomically with the play. Sound and card motion have independent, remembered
controls. Motion initially respects reduced-motion settings. A brief filtered
paper sound starts only after a browser user gesture; blocked audio never stops
gameplay. Chrome/Chromium and Safari/WebKit are the required browser targets.
